# 0.16：编辑手感与配色

0.16 集中改善编辑体验：字号缩放、字体与中文回退、随主题变化的配色与当前行高亮，以及 Python 等代码文件最常用的编辑操作。仍然使用原生 WPF，普通阅读不启动网页进程或终端，不新增常驻服务。

## 字号缩放

- 编辑器内 Ctrl+滚轮，或 Ctrl+= / Ctrl+- 缩放编辑字号；每档 10%，范围 60%–250%；Ctrl+0 重置 100%。
- 底栏在非 100% 时显示“缩放 N%”；命令面板提供“放大编辑字号”“缩小编辑字号”“重置字号缩放”三条命令。
- 外观面板的“字号”滑块是基础字号（10–40），缩放是在该基础上乘以比例；面板另有字体实时预览与“重置字号缩放（100%）”按钮。
- 阅读视图的 Ctrl+滚轮仍用于内容缩放，与编辑字号缩放相互独立；Shift+滚轮横向滚动保持原行为。

## 字体适配与中文回退

字体列表扩展为 Cascadia Code、Cascadia Mono、Consolas、JetBrains Mono、Fira Code、Source Code Pro、Courier New、Microsoft YaHei UI 与 Segoe UI。非中文字体（含 Consolas、JetBrains 等）保留自身 ASCII 字形，CJK 字符统一回退 Microsoft YaHei UI，中文注释与中文字符串不再显示方块。外观面板提供“Aa 中文代码 0123 ()[]”字体实时预览。

## 配色与对比度

四套主题（薄荷、暖白、浅紫、深色）各自新增“当前行”高亮 token，编辑器当前行随主题变化；语法高亮继续跟随主题切换。编辑器选中色与前景随主题。回归校验注释、字符串、数字、关键字、属性、标题 6 个语法色对表面色的对比度不低于 4.5:1，四套主题全部覆盖。

## 代码编辑便利

- Python 自动缩进：上一行以 `:` 结尾时下一行 +4；else、elif、except、finally、case 开头的行自动回退一级。
- 其它代码文件复制上一行缩进，并在上一行以 `{`、`(`、`[` 结尾时 +4。
- Tab 在有多行选区时块缩进，无选区时仍是普通输入；Shift+Tab 反缩进当前行或选中行。
- `(`、`[`、`{` 与引号自动配对：有选区时包裹选区，输入已有闭括号时跳过而不重复插入；只对代码文件生效，Markdown 与纯文本保持原有输入行为。
- Ctrl+/ 切换行注释：`#`（Python、shell、配置等）、`//`（C 系、JS/TS、Java、Go 等）、`--`（SQL、Lua、Haskell）、`rem`（批处理）；HTML/XML/SVG/XAML 等用 `<!-- -->` 整块切换。
- Ctrl+D 复制当前行或选区；Alt+↑/↓ 上移或下移行。
- 每次编辑操作合并为一次撤销。

## 快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 放大 / 缩小编辑字号 | Ctrl+滚轮（编辑器内）或 `Ctrl+=` / `Ctrl+-` |
| 重置编辑字号 | `Ctrl+0` |
| 切换行注释 | `Ctrl+/` |
| 复制行 / 选区 | `Ctrl+D` |
| 上移 / 下移行 | `Alt+↑` / `Alt+↓` |
| 块缩进 / 反缩进 | `Tab` / `Shift+Tab` |
