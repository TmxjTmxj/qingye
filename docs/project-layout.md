# 项目目录

| 位置 | 用途 |
| --- | --- |
| `app/` | 当前原生便携程序与依赖；双击 `轻页.exe` |
| `release/` | 最新 ZIP、大小与 SHA256 校验；旧版在 `archive/` |
| `src/Core/` | 文件、格式、搜索及系统 ConPTY 会话 |
| `src/UI/` | WPF 编辑阅读界面与 CMD 面板 |
| `src/Assets/` | 可编辑图标源、多尺寸 ICO 和 SVG 控件图标 |
| `tests/` | 核心、实际窗口、系统选择器及多窗口/CMD 验收 |
| `scripts/` | 原生依赖恢复、构建、测试、测量、打包与整理 |
| `docs/` | 当前说明、发布方法与历史版本记录 |
| `build/` | 可再生成的本机构建及原生依赖缓存 |
| `artifacts/` | 本机性能记录与真实窗口截图，不进入源码或 ZIP |

0.12 不再含 Agent/Harness/Node、模型配置入口或 SDK 准备步骤。旧版本文档只作历史参考。本机原有模型配置或会话数据不自动删除，不读取、不进入当前便携包。

目录根 `启动轻页.cmd` 指向 `app/轻页.exe`；多次启动会打开相互独立的窗口。`scripts/package.ps1` 从明确清单生成便携包，不收集 `app/` 中额外的个人文件；更新时保留已有示例修改。
