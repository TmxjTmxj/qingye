# 轻页

当前版本以根目录 [VERSION](../VERSION) 为唯一来源；构建与便携包名称自动读取它。发布说明模板与 SHA256 校验方法见 [发布准备](releasing.md)。

一个用于 Windows 的轻量文件阅读与简单文本编辑器。打开即用，默认一份文件；需要更多内容时再手动导入。

0.11.1 优化文件切换与快速打开：切换标签复用现有控件，减少重复布局；快速打开在大列表下合并连续输入，提供随主题变化的选中态。标签更紧凑，当前文件有强调色指示；修复标签右键指定第一/第二栏的目标错误。详见 [本轮优化与验证](lightweight-0.11.1.md)。

## 使用

解压便携包，双击 `轻页.exe`。请保留同目录的 DLL 和配置文件；无需安装、登录或选择项目。程序可直接接收文件路径参数，也可把文件拖到窗口。正在运行时再次打开文件，会交给已有窗口。

在源码项目目录中，双击根目录 `轻页.lnk` 或 `启动轻页.cmd` 即可启动最新版。当前程序集中放在 `app/`，最新便携包在 `release/`，历史版本保留在 `release/archive/`。完整目录说明见 [项目目录](project-layout.md)。

- **打开 / Ctrl+O**：替换本次文件列表，只留下打开的这一份；有未保存修改时先集中处理。
- 连续打开按顺序处理，最多等待 4 个请求；超出会取消最早等待的一项并提示，打开失败后队列仍继续。
- **导入 / Ctrl+Shift+O**：主动添加更多文件。**导入工作区 / Ctrl+K**：临时加载一个目录，只在展开时读取下一层。
- **保存 / Ctrl+S**、**另存为 / Ctrl+Shift+S**。未保存内容只在内存里，关闭时可保存选中、全部放弃或取消。
- **外观与布局**：薄荷、暖白、浅紫、深色四套配色；支持强调色、字体、字号、换行和行号。默认不保存偏好，可主动勾选“记住外观”。
- 代码块、表格、引用及源码高亮随主题切换，已打开的阅读内容无需重新打开文件。
- **布局**：一栏、双文件对照、代码与预览。拖动分隔线调整比例，标题菜单调整上下/左右排列、交换文件和预览位置。标签切换当前编辑栏，右键可指定第一/第二栏。
- **文件视图**：打开后按类型选择展示方式，右上角切换阅读/结构/表格、源码和对照；每份文件的选择只在本次会话保留。**Ctrl+E** 切换阅读与源码，**Ctrl+Shift+V** 打开源码与预览对照。箭头按钮交给系统关联软件打开。
- **文件与大纲 / Ctrl+Shift+B**：左侧栏列出本次打开的文件；导入工作区后在同一栏显示目录。切到“大纲”会按类型列出 Markdown 标题、JSON 键、XML 元素、配置键、CSV 列和文本章节，点击跳到源码或阅读位置。
- **原位编辑 / Ctrl+Shift+E**（Markdown）：在排版内容中直接编辑，工具栏支持标题、粗斜体、删除线、行内代码、列表、引用、代码块、表格、链接和本地图片。仅支持轻页定义的 Markdown 子集；保存或切回源码时按该子集整理格式，遇到不支持的结构会提示并保留源码视图。
- **导出 / 另存为其他格式**：工具栏“导出”或保存菜单，支持 TXT、Markdown、HTML、DOCX、CSV、XLSX 和 PDF。DOCX/PPTX/RTF/XLSX 等只读内容也可导出副本，原文件不变；PDF 使用系统 WebView2，只对可预览内容可用。
- **Agent / Ctrl+Alt+A**：右侧是原生对话面板，与阅读/编辑器并排，分隔线可调宽；820 像素宽仍并排，390 像素进入专注。面板只保留对话、工具步骤、审批、临时历史、改动核对与附件；运行时是首次打开面板时启动、之后常驻的内置 DSH SDK 进程（stdio JSON-RPC，无 WebView2）。支持真实任务状态、精确编辑（按唯一原文片段替换，批准后写入）、分层列出/正则搜索、临时会话续聊，以及不重启运行时的“新任务”。Agent 写入磁盘后，已打开的干净缓冲区原地刷新并可用一次撤销恢复，脏缓冲区不会被覆盖；本次改动可查看差异、带冲突检查撤销。权限可选只读、每次确认或自动编辑当前工作区；四套主题下界面跟随轻页配色。Agent 快捷键：Ctrl+Alt+F 并排/专注、Ctrl+Alt+N 新任务、Ctrl+Alt+H 历史、Ctrl+Alt+M 模型、Ctrl+Alt+S 停止当前轮、Ctrl+L 聚焦输入框；输入框 Enter 发送、Shift+Enter 换行，Esc 先关历史再交还焦点。
- **快速打开 / Ctrl+P**：立即显示本次打开的文件（包括未保存文档），工作区文件在后台按需查找；输入名称或路径过滤，也支持按文件名字符顺序模糊匹配，方向键选择、Enter 打开、Esc 关闭。最多扫描 2000 个文件及 6 层目录，关闭后不保留索引。**Ctrl+Tab / Ctrl+Shift+Tab** 或 **Ctrl+PageDown / Ctrl+PageUp** 切换文件。
- **打印 / Ctrl+Alt+P**：打印当前阅读内容；也可从保存菜单进入。
- **按类型排版**：纯文本自然换行、不显示行号；日志、代码和配置使用等宽字体与原始行序。外观的“阅读设置”可关闭按类型默认值，改为手动字体和换行。
- **窗口与阅读宽度**：可拖动窗口边缘和四角自由缩放，已取消原 820×540 最小尺寸限制。阅读内容铺满可用宽度，左右只保留 16–24 像素内边距；窄窗口中工具收入“更多”，文件信息与视图按钮分行，源码对照自动上下排列。
- **搜索 / Ctrl+F**：大小写、正则、替换全部；导入工作区后可勾选“工作区”异步搜索目录，结果显示路径、行号与片段；**Ctrl+G** 跳转行；**Ctrl++ / Ctrl+-** 调整字号。
- 底栏“可编辑 / 只读”切换普通文本的编辑状态。超过 32 MiB 的文本分段只读，通常每段 1 MiB；超过 256 KiB 且含超长行的文件使用 64 KiB 小段，通过底栏“上一段 / 下一段”阅读；大文件或超长行关闭换行以避免大量排版。

## 文件范围

| 内容 | 支持方式 |
| --- | --- |
| PPTX | 只读提取每页标题、正文和表格；最多 100 页；不还原图片、动画、图表、备注和原始版式 |
| EPUB | 原生章节阅读，不启动网页进程；支持标题、列表、表格、图片和章节跳转；加密/DRM 文件拒绝 |
| TXT、日志、Markdown、JSON、XML、YAML、INI、TOML、CSV/TSV、各类源码和未知文本扩展名 | 阅读与编辑；部分语言语法高亮；保持编码、BOM 与原有换行 |
| HTML / CSS / JS、SVG | 源码编辑与按需预览；相对资源及已打开文件的未保存修改可进入预览 |
| 前端和后端源码 | 导入两个文件即可同屏编辑；后端源码本身不会被自动执行 |
| Markdown | 原生排版阅读，不启动网页进程；支持标题、列表、表格、代码、引用和限定范围本地图片；Ctrl+滚轮缩放；可选原位编辑（受限子集，保存时整理格式），支持剪贴板图片粘贴与表格 Tab 导航 |
| CSV / TSV | 原始文本编辑及限量表格内容预览 |
| PNG / JPEG / BMP / GIF / TIFF / ICO | 图片查看、适应窗口或查看解码尺寸；不修改像素 |
| PDF | 查看、搜索和缩放由系统网页运行时提供；不改写 PDF |
| JSON / XML / XAML / XML 配置 | 默认可展开结构视图；保留值、字段顺序和大整数文字；可切换语法高亮源码。结构视图限 512 KiB，超限或语法错误可继续在源码中查看 |
| YAML / INI / TOML / ENV 等配置 | 等宽源码、行号、键值和注释高亮；高亮不代替语法校验。未知语言和扩展名保留原始文本 |
| DOCX | 默认原生基础排版：标题、段落、粗斜体和表格，支持 Transitional/Strict 正文与内容控件；不还原图片、页眉页脚、复杂列表和完整分页 |
| XLSX | 默认只读工作表，支持切换工作表、前 500 行和 50 列及常用内置数字/日期/百分比格式；公式只显示文件中的缓存值，缺失会标注，不重算、不还原自定义格式/合并单元格/图表 |
| RTF | 默认原生富文本只读阅读，限 4 MiB |
| 二进制或无法可靠解码的内容 | 前 64 KB 十六进制只读查看，可用系统关联软件打开 |

支持 UTF-8（有/无 BOM）、UTF-16 LE/BE、UTF-32 BOM、GB18030，也可从编码菜单重读/转换。无法自动辨认的编码需要手动选择。保存失败、外部修改或原文件被删除时保留当前内容，不静默覆盖。右键标签可关闭其他文件、定位文件或交给系统软件。

GB18030 大文本首次打开会建立内存中的字符对齐索引，后续翻页直接定位。索引最多保留四个文件的偏移元数据，不保存文本或写磁盘缓存；文件大小或时间戳变化会重建。129 MiB 夹具实测首次打开含建索引 246.15 ms，热读首页/末页中位数 4.32/4.24 ms（0.98 倍）；此数据仅代表本机测试条件。

HTML 默认显示源码，点击“网页”或“对照”才启动预览。网页预览可连接你已运行的 `http://localhost:端口` / `http://127.0.0.1:端口` 服务。编辑器不会启动后端、安装依赖或持续运行开发服务器。静态文件资源读取限于入口文件所在目录，父目录资源请通过已有本机服务器访问。

没有一种统一标准能完整展示所有文件格式。轻页为已支持格式采用对应的阅读惯例；未支持的专有格式保留文本或十六进制查看，并可一键使用系统软件。格式化展示不会改写源文件。Markdown 阅读与源码/对照是独立视图；原位编辑是可选的受限子集，保存时会规范化格式，不能无损往返所有 Markdown 扩展语法。

导出为 DOCX、XLSX、CSV 或 HTML 只保留轻页能读取的文本、基础标题、列表和表格，不还原图片、完整样式、公式或动画；转换只写新文件，不修改原文件，也不会把当前文档切换成导出格式。完整的范围与限制见 [编辑与导出](editing-and-export-0.5.md)。

## 内置 Harness 与文件权限

Agent 是内置的官方 DeepSeek Harness 定向运行时：固定 `@deepseek-ai/dsh@0.2.1-rc.5`（`sdk-minimal` 树）与 Node 24.18.0。轻页首次打开面板时启动一个常驻本机子进程，经 stdio JSON-RPC 驱动；界面是纯原生 WPF，不再用 WebView2 承载 Harness 页面。文件工具与写审批走编辑器自己拥有的一次性令牌 TCP 回环桥；没有本地 HTTP 服务、页面注入或浏览器临时目录。会话循环、工具事件、模型与审批链路仍由官方 Harness SDK 运行；无需另装 Node，不会在用户运行时自动安装依赖。

打开一个文件后，从右侧 Agent 面板开始；左侧仍是文件树，中间仍是原生阅读/编辑器。面板没有独立的工作区管理：范围要么是当前文件，要么是你主动“导入工作区”的目录。选择过的范围不会因模型给出绝对路径而扩大，切换文件范围会结束旧运行并重新绑定当前范围。

模型配置仍在程序目录或项目根目录的 `模型.txt`：

```text
api地址：https://你的 OpenAI 兼容端点
key：sk-...
模型：模型名
```

- **只读**：可以查看和搜索，禁止写文件。
- **每次确认**（默认）：每次修改先在面板中展示有界的 +/- 行式差异（只含变化附近的行，过长时截取显示，完整内容仍在工具参数中），批准后才落盘。
- **精确编辑**：Agent 优先按唯一原文片段替换（`replace_all` 可全部替换），也可新建文件、按 1–6 层列出目录、用正则和上下文搜索；新建只在导入的工作区允许，单文件仍逐次确认。
- **自动编辑工作区**：仅对当前主动导入的文件夹生效，允许在已有目录内新建或修改文本文件；单文件仍逐次确认。切回只读或每次确认，会撤销尚未执行的自动写入提案。下次启动恢复默认权限。
- 路径越界、目录链接、密钥文件、Git 内部文件和 Harness 自身数据目录受保护。未保存缓冲区不会被覆盖，写入前复核磁盘版本；读取已打开文件使用最新缓冲区。Agent 写入磁盘后，已打开的干净编辑器缓冲区会原地刷新（一次撤销可恢复），脏缓冲区不被覆盖。没有开放终端、删除文件、任意网络或插件安装工具。
- **历史与数据（临时会话）**：面板对话与输入草稿只保存在本次运行的内存中，退出或“清空”即失效，不写 JSONL、不生成会话文件；旧版本留在程序目录的 `agent-history/`、`agent-data/` 不会自动读取或删除，面板“清理旧版存档…”可显式删除这两类目录（拒绝目录链接，不撤销已写入文件）。关闭面板不停止运行时；退出轻页时结束子进程。删除历史或退出不会撤销已写入的文件。
- 密钥仅从原模型文件经环境变量传给内置运行时，不写入补丁配置、历史或便携包。模型请求通过官方兼容适配器连接配置端点；遥测已关闭。

运行时保存在 `Harness/`，首次打开面板时启动并常驻，退出轻页时关闭，没有独立常驻服务。程序仍使用系统 .NET Framework 4.8；Agent 不再需要 WebView2，网页/PDF/SVG 预览仍依赖系统 WebView2。原生文件阅读不启动 Node；0.11 起的精简包只保留 SDK 实际依赖（ZIP 实测约 69.6 MiB、解压目录约 212.4 MiB，准确字节数与 SHA256 见 `release/package-info.txt` 和 `release/SHA256.txt`），请保留完整目录。

集成、边界、验证命令和实际测量见 [Harness 集成记录](harness-integration.md)；稳定性、临时会话与精简包见 [0.11 Agent 稳定性与轻量化](agent-0.11.md)，原生 SDK 协议细节见 [0.10 原生 SDK 客户端](agent-0.10.md)，0.9 的 WebView 面板记录保留为 [历史文档](agent-0.9.md)。真实外部模型端点的本轮速度、流式兼容性及资源占用均为**未测量**；真实 Harness 与本机合成模型的端到端验收不能替代该结果。

文件阅读编辑器不写最近文件列表、文档备份、文件内容缓存或工作区配置，每次启动为空白文档。Agent 对话是本次运行的临时会话，退出即清空；程序目录中若存在旧版本留下的 `agent-history/`、`agent-data/`，只在用户主动“清理旧版存档…”时删除。外观偏好默认关闭，开启后只把界面参数写到程序目录的 `preferences.xml`；取消勾选会删除该文件。手动保存或明确批准 Agent 修改后才改写目标文件。

纯文本模式不启动网页进程。网页/PDF/SVG 预览使用共享 WebView2 Runtime、独立临时目录和按需进程；收起预览或正常退出会释放并清理。异常强制断电/终止可能留下临时目录；Windows 文件选择器、系统日志、NTFS 和交换文件的系统痕迹不属于本程序的可控范围，因此这里的“不留存”指应用不保留临时预览目录；Agent 会话也不在本次运行之外保留，旧版存档需用户显式清理。

0.3.1 实测文本暖启动约 0.34 秒、普通关闭约 0.04 秒，空白窗口工作集约 83 MiB，1/10 MiB 文本从启动到内容就绪约 0.38/0.44 秒。沿用的原生 Markdown 阅读布局首次显示约 0.20 秒，整个阅读窗口约 93 MiB（含测试宿主），无网页进程；千文件目录首批约 48 毫秒，每批最多 120 文件/120 目录，可继续加载。网页预览关闭与缓存清理约 0.36 秒；浏览器进程额外工作集合计约 315 MiB（共享页有重复统计）。网页/PDF 预览属于可选功能，其资源要求明显高于原生文本和 Markdown 阅读。测量条件和限制见 `docs/performance.md`。

Windows x64，依赖系统 .NET Framework 4.8；网页类预览需要系统 Microsoft Edge WebView2 Runtime。当前电脑已具备这些运行环境。普通文本模式无须下载网页运行时。程序没有自动更新、后台托盘、项目索引或账户服务。

## 源码构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/restore.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-harness.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/measure.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

编译使用系统 Framework C# 编译器；不需要安装 .NET SDK。原生依赖锁定在 `packages.lock.json`；Harness 依赖锁定在 `src/Harness/package-lock.json`。首次准备 Harness 需要联网，之后可用 `scripts/prepare-harness.ps1 -Offline` 复用已校验的缓存；修改 `src/Harness/*.mjs` 后，`build.ps1` 会把它们同步到 `build/harness-runtime`，打包前须重新执行 `scripts/prepare-harness.ps1 -Offline` 刷新 `runtime-files.json`。开发构建均位于 `build`。测试使用真实临时文件和实际 WPF 控件，发布包不包含测试程序、工具链或设计图片。第三方许可见 `../licenses`。

窗口区域按 Toolbar、DocumentBar、AppearancePopup、Footer、TabStrip 等原生 UserControl 分开；MainWindow 只协调会话、布局与命令。测试使用 internal 钩子，不依赖窗口私有字段的反射。
