# 原生界面设计核对

目标：`docs/design/qingye-integrated.png` 的明亮薄荷整合方案，同时保留暖白和浅紫、可调整的面板。实现为真实 Windows 原生应用，网页浏览器预览位于可选内容区。

已从运行中的 WPF 控件渲染并用 WebView2 官方页面捕获合成真实界面截图（现统一在 `artifacts/ui/`）：`native-reading.png`、`native-integrated.png`、`native-lilac.png`、`native-bottom.png`、`native-compact.png`。截图使用本项目真实示例文件，不是预制界面图片或不可交互外壳。PDF 截图 `native-pdf.png` 已目视确认真实页面文字显示。

核对结果：顶部简明工具栏、薄荷侧栏、细分隔线、低饱和代码颜色、双代码区与右侧页面预览均可用。中文文本使用微软雅黑回退字体，代码 ASCII 保持等宽字体。单文件隐藏多文件标签区；导入后显示标签与目录，普通启动直接到空白编辑区。

真实控件测试覆盖：启动可编辑、打开替换、主动导入、切换三套配色和布局保留内容、查找替换、大文件翻页、原始文件编码与换行、关闭决策。实际网页验证覆盖未保存内容、相对 CSS、Markdown 脚本限制、预览重新创建、PDF 查看和退出清理。900×600 紧凑布局截图作为最低窗口邻近尺寸检查；标题栏工具均保留。

与视觉概念的合理差异：系统字体和原生控件在不同 DPI 下会略有不同；滚动条、文件选择器和 PDF 内置工具栏沿用系统组件。页内示例是用于展示预览的可编辑 HTML，不属于每次启动的内容。Office 内容查看没有完整排版还原，GIF 当前显示首帧。

0.2原生阅读核对：`artifacts/ui/native-markdown.png` 是真实源码与原生阅读并排窗口。标题、段落、列表、代码与表格已目视核对；段落左对齐，表格行距更紧凑，源码标题采用柔和绿色。阅读链接随强调色变化，可Ctrl+滚轮缩放。目录首批后台读取、右键指定编辑栏、动态资源请求释放和原生Markdown内容完整性均已通过实际控件测试。
