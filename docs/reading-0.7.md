# 轻页 0.7：阅读与交互增强

本页记录该阶段行为；当前 Agent 的会话保存、流式、状态与自适应布局见 [原生 Agent 体验改造](agent-experience.md)。

0.7 在 0.6 Agent 之上补齐阅读与日常操作：EPUB、工作区搜索、深色主题、快速打开、Markdown 图片粘贴与表格 Tab、打印，以及 Agent 与顶栏的交互重做。

## EPUB

- 原生 ZIP + OPF + XHTML 阅读，不启动 WebView2。
- 支持：标题、段落、粗斜体、行内代码、链接、列表、引用、代码块、表格、图片；章节下拉切换。
- 内部章节链接可跳转；外部链接交给系统浏览器。
- 限制：最多 200 章、每章 2 MiB、全书章节总计 32 MiB、图片每张 5 MiB、总计 24 MiB；超过时截断或跳过。
- 受 DRM/加密保护的 EPUB 会被拒绝并明确提示；不提取到磁盘。
- 图片仅从书内读取；外部图片 URL 不加载。
- 章节标题优先取导航（EPUB3 nav / NCX），没有导航时取 `<title>` 或首个 h1/h2。

## 工作区搜索

- 搜索栏勾选“工作区”（导入工作区后出现），输入后回车。
- 异步扫描，不建索引、不写缓存；结果弹出列表，显示相对路径、行号和片段；点击打开并跳到行。
- 跳过 `.git`、`node_modules`、`.venv`、`bin`、`obj`、`packages`、重解析点；单文件上限 1 MiB，最多 500 个文件、200 条结果。
- UTF-8 失败时按 GB18030 读取；含 NUL 的二进制文件跳过。

## 深色主题

- 薄荷、暖白、浅紫、深色四套；深色同时覆盖框架、内容、代码块、引用、表格和语法高亮。
- 内置主题的强调色仍可自定义。

## 快速打开

- `Ctrl+P`：列出本次文件与工作区文件（最多 2000 个），输入过滤，上下选择、Enter 打开、Esc 关闭。
- 仅内存列表，不写最近文件。

## Markdown 原位编辑增强

- 剪贴板图片：原位编辑中 Ctrl+V，按提示命名后保存到同目录 `assets/`，并插入 Markdown 图片。
- 表格：Tab / Shift+Tab 在单元格之间移动；到末尾单元格时保持默认 Tab 行为。

## 打印

- `Ctrl+Alt+P` 或保存菜单“打印当前阅读内容”。
- 原生阅读的 FlowDocument 直接打印；纯文本阅读构造分页文档打印；实际打印由系统 PrintDialog 处理。

## 顶栏与 Agent 交互

- 顶栏按“文件 / 保存 / 视图 / Agent”分组，加入细分隔线；导出移入保存菜单，保存按钮带下拉提示。
- Agent 固定在顶栏右侧，使用强调色；窄窗口收进“更多”，快捷键 `Ctrl+Alt+A`。
- Agent 面板：
  - 可拖动分隔条调整宽度（300–620 px，记住外观时保存）。
  - 附加上下文文件（纸夹按钮），显示可移除的上下文标签，发送时带入提示。
  - “本次改动”列表显示已应用文件，点击可直接打开。
  - 请求中显示已等待秒数；支持停止、重试、复制消息；拒绝写入会显示在工具轨迹中。
  - 对话只存在本次会话，不写盘。
