# 0.15：收尾与手感

0.15 是 0.14 系列之后的收尾版本：修复打印、Markdown 阅读提示与设置持久化里“看起来能用、实际没有反馈”的问题，并补齐便携包的文档闭环。仍然使用原生 WPF，普通阅读不启动网页进程或终端，没有新增常驻服务。

## 修复与体验升级

- **打印有明确落点**：打印前先确认当前视图能否打印；没有阅读内容时自动切到阅读视图再打印。图片、PDF、网页、EPUB 等无法打印的内容会直接提示用系统关联软件打开后打印，不再弹出打印对话框却没有输出。
- **Markdown HTML 提示**：排版阅读检测到原始 HTML 块时，在内容顶部显示说明，明确这部分按纯文本显示；需要网页效果时可用系统关联软件打开。不再毫无提示地露出裸标签。
- **“记住外观”的范围**：“记住外观”继续保存配色、强调色、字体、换行与行号等外观项；一栏、对照、预览等布局模式改为仅本次会话状态，不再写入设置，避免“存了却不生效”的误导。
- **可访问名与细节**：CSV 等视图切换按钮的可访问名与可见文字一致；命令面板不可最大化，减少误操作；工具栏“命令”使用独立图标。
- **滚动与手感**：滚轮基础位移仍按系统“每次滚动 3 行”×行高（编辑器约 64 px、阅读视图约 84 px），但改为按比例累积，30/15 这类高分辨率或触摸板小增量不再被丢弃；快速连续滚动时最高约 2.2 倍加速。编辑器、Markdown、EPUB 与 Office 阅读视图手感一致；Ctrl+滚轮缩放、Shift+滚轮横向滚动保持原行为。`tests/ScrollProbe.cs` 为测量工具，不进入便携包。

## 便携包与文档

- `README.md` 以 `app/README.md` 进入便携包，包内 `docs/usage.md` 返回项目首页的链接不再失效。
- 顶部 Logo 改用 `docs/images/qingye.png`，GitHub 与包内均可用；图标随包分发。
- 过时的 `docs/reading-0.7.md`、`docs/performance.md` 不再打包；终端组件表补充 `@xterm/addon-search@0.16.0`（MIT，`vendor-lock.json` 记录哈希）。
- 发布说明按“本地构建、尚未发布到 GitHub”的口径更新；GitHub 最新发布仍为 0.13.0，0.15.1 的便携包在本地 `release/` 下。

## 验证

常规回归运行 `scripts/test.ps1`，包括核心测试、界面、文件选择器、实际多窗口/CMD 与体验测试。0.15 新增回归覆盖：设置中的布局不持久化、打印前准备与不可打印提示、Markdown HTML 提示、视图按钮可访问名、滚轮按比例累积与快速滚动加速。本轮已实测通过：Core 65 / UI 69 / Picker 4 / Experience 11 / Usability 29，合计 178 PASS / 0 FAIL，构建 0.15.1.0。本机滚轮探针（`tests/ScrollProbe.cs`）测得编辑器约 0.51 ms/档、阅读视图约 1.9 ms/档（含一次布局与渲染，仅代表本机条件）。

便携包由 `scripts/package.ps1` 生成，`tests/ScriptTests.ps1` 核对白名单、ZIP 内路径与逐文件 SHA256。0.15.1 便携 ZIP 约 1.50 MiB、解压约 3.94 MiB；精确字节与 SHA256 以 `release/package-info.txt`、`release/SHA256.txt` 为准（会随文档改动小幅变化，不在文档中固化）。

本机隐藏窗口实测：window_create 约 365–392 ms、blank_working_set 约 88.5 MiB、private 约 88.9–90.7 MiB、markdig_loaded=False；隐藏窗口热启动中位约 425–436 ms，空白窗口工作集 86.7–87.3 MiB；打开 Markdown 阅读并完成排版后工作集约 112 MiB（阅读排版与 Markdig 加载的增量）。测量仅代表本机条件，未清理系统缓存。
