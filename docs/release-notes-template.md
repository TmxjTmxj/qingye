# 轻页发布说明模板

版本：从随包 VERSION 读取。发布日期：填写实际日期。

## 变更

- 用户遇到的问题、修复后的行为及适用文件类型。
- 性能：填写夹具、机器上实测数字及输出文件；没有运行则填“未测量”。

## 验证

- `scripts/test.ps1`：填写核心、UI、系统选择器和脚本检查数量，附完整输出位置。
- 三主题及宽窄窗口：填写已观察的截图位置。
- 便携包：填写 package-info.txt 中的实际大小，附 SHA256.txt。

## 已知边界

- PPTX 为只读标题、正文、表格提取；不还原图片、动画、图表、讲者备注和原始版式。
- 保留文件、XML、路径及排版预算；超出时以界面提示为准。
- 网页和 PDF 预览按需使用系统 WebView2 Runtime。

发布前核对 [发布准备](releasing.md)。此模板不触发远程发布。
