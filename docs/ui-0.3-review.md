# 轻页 0.3 界面修正

基准为已选设计稿 `docs/design/qingye-integrated.png`，1487×1058。当前审查先重新运行应用捕获截图，再逐项核对；已有0.2功能保留。

1. 工具栏：统一为Lucide原始矢量图标，固定图标盒；纯图标按钮不再带文字间距。窗口控制独立占位，窄窗口工具栏变为图标与工具提示。最低820×540的实际控件边界测试检查按钮互不覆盖、图标不超出按钮。
2. 内容层级：标签栏移到编辑区域，左侧工作区与右侧预览有独立起点；默认预览占工作区48%，上下编辑区54/46，接近设计稿比例。文件列表、标签和标题都有类型图标；文件名省略显示保留完整工具提示。状态栏增加路径层级并把编码/换行/光标信息放右侧。
3. 外观面板：392px主题色卡、强调色及选中环、完整宽度的布局卡片。阅读偏好在展开区，默认仍不留存。主题与布局都可交互，不是截图外壳。
4. 小窗口及阅读模式：溢出标签提供水平滚动；图片/PDF阅读模式保留标签导航，切回文本恢复编辑器。

实际证据（现统一在 `artifacts/ui/`）：`design-integrated.png`、`design-appearance.png`与设计稿同尺寸；`design-minimum.png`和`design-bottom-minimum.png`是820×540；`design-150-percent.png`为150%像素密度的离屏渲染，检验矢量清晰度，未更改用户显示器DPI，不能称为真实跨显示器测试。例子网页来自可编辑文件，其文字及页面内容不属于编辑器界面的1:1匹配要求。

最终只读审查发现两个重要回归：阅读模式标签消失、窄窗口更多标签不可访问。对应真实控件测试观察失败后修复通过；完整62测试通过。布局卡宽度与强调色反馈直接属于本次视觉任务的验收点，已一并修正。无未解决的审查发现。

实现取舍：按已批准设计目标修正原生界面，保留系统滚动条和文件选择器，以保持轻量；图标取自固定提交的官方库，不加运行时下载或大型UI依赖。新版源码和截图记录在项目内；Obsidian不在授权写入范围，未写入外部记忆库。
