# 轻页 0.6：本地 Agent 与模型配置

> 历史记录：当前版本已按用户新决定改为内置官方 Harness、右侧栏和纯内存对话。以下持久历史与原生循环属于旧版行为，现状见 [Harness 集成记录](harness-integration.md)。

本页记录初始实现。当前会话持久化、流式、内联审批及自适应布局以 [原生 Agent 体验改造](agent-experience.md) 为准。

0.6 增加一个受约束的文件 Agent。它直连 OpenAI 兼容端点，不启动本地 harness，因此没有端口占用，也不会和机器上的 Codex/其它 harness 抢占端口。

## 接入方式

`模型.txt`（程序目录或项目根目录）是唯一配置源：

```text
api地址：https://example.com:4000
key：sk-...
模型：Ali-dashscope/GLM-5.3-Flash
```

- 解析支持中文/英文标签、全角/半角冒号、`#`/`;` 注释。
- 地址必须为 `https`；只有 `http://127.0.0.1` / `localhost` 才允许明文。
- 客户端显式启用 TLS 1.2；.NET Framework 4.8 的默认协商在部分端点上会失败。
- 默认端点：`{地址}/v1/chat/completions`；地址已以 `/v1` 或 `/chat/completions` 结尾时不会重复拼接。
- 密钥只保存在 `模型.txt`，不写入 `preferences.xml`、日志或便携包；错误信息中会替换为 `sk-***`。
- 设置窗口可编辑地址、模型和密钥，并提供“测试连接”；保存使用临时文件 + 替换。

## 工作区沙箱

Agent 的所有路径都经 `AgentWorkspace`：

- **导入工作区**：只能访问该根目录内的相对路径；`..`、绝对路径越界、重解析点（junction/symlink）都会被拒绝。
- **只打开一个文件**：只能读写这个文件；`list_files` 只返回它，`search_files` 只搜索它；`write_file` 新建会被拒绝。
- **受保护文件**：`模型.txt`、`preferences.xml`、`.env`/`.env.*`、`credentials.json`、`secrets.*`、`id_rsa`、`id_ed25519`、`.pfx/.p12/.key/.pem`、`.git` 目录，读写均拒绝。
- **没有** shell、删除、重命名、复制、网络请求工具；工具只有 `list_files`、`read_file`、`search_files`、`write_file`。
- 读取上限 256 KiB/次；写入 512 KiB/次；列表 200 项；搜索 50 条/200 个文件；单轮最多 8 个模型步骤、最多新建 5 个文件；请求超时默认 90 秒。
- 读取打开中的文件时使用编辑器缓冲区；文件有未保存修改（或正在原位编辑）时拒绝写入，避免覆盖用户内容。

## 写入确认

`write_file` 不直接落盘：

1. Agent 提出完整的新内容；
2. 弹出 diff（新增行绿色、删除行红色）；
3. 用户点“应用修改”后才写入，点“拒绝”则返回 rejected；
4. 写入后如果文件已在会话中打开，会重新载入；新建文件只在工作区模式允许。

## UI

- 工具栏“Agent”或 `Ctrl+Alt+A` 打开右侧面板（窗口宽度至少 1000 像素）。
- 面板显示模型名、工作区/单文件上下文、工具调用轨迹和对话。
- 齿轮打开模型配置；新对话清空当前面板。
- 失败、超时、取消都在面板内显示；密钥不会出现在消息里。

## 验证与限制

- 完整回归 128 项：61 核心、58 原生 UI、4 系统选择器、5 脚本；原始输出 `artifacts/metrics/verification-0.6.0.txt`。
- 核心测试覆盖：配置解析/保存/脱敏、工作区越界、单文件禁止新建、受保护文件、工具读写搜索、审批/拒绝循环、客户端工具调用解析与错误脱敏。
- 实际端点已用最小请求验证：`HTTP OK`，模型返回工具调用 `list_files`；一次工具调用请求约 34 秒，属于模型侧延迟。
- 实际端点已完成一次完整工具循环：模型调用 `read_file`、`list_files`、`write_file`，diff 审批 1 次，临时文件内容被改为指定文本，未新建文件；密钥未出现在输出中。
- 当前为**非流式**请求：发出后等待完整响应；工具步骤多时面板只显示“请求中…”，可停止。
- 模型必须支持 OpenAI 风格 function calling；不支持时只会返回文字，不会执行文件操作。
- Agent 不是通用编码代理：没有编译/测试/终端能力，也不做代码索引；它只适合在当前工作区做读取、搜索和小范围文本修改。
